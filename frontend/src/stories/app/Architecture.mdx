# Muzloft UI

Истории сгруппированы по архитектурным слоям приложения:

- **App** — точка входа и общая композиция приложения.
- **Pages** — экраны, связанные с маршрутами.
- **Widgets** — самостоятельные крупные блоки интерфейса.
- **Features** — пользовательские действия и сценарии.
- **Entities** — UI предметных сущностей.
- **Shared** — общие UI-компоненты.

Тестовые данные находятся в `src/stories/fixtures`, а общие декораторы и
вспомогательные компоненты — в `src/stories/helpers`.
